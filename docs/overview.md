# Project overview

SafeX AI is an offline Android security prototype for a hackathon. It checks user-provided messages, links, screenshots, QR images and bounded files, and optionally analyzes visible notifications from supported apps. Clear local evidence drives ALLOW, WARN or BLOCK results. Blocked links cannot be opened through the result UI.

See [features](features.md), [architecture](architecture.md), [privacy](privacy.md), [model card](ml-model.md), [setup](setup.md) and [demo](demo.md) for current behavior and limitations. The [upgrade plan](hackathon-upgrade-plan.md) records the original audit and proposed acceptance criteria; current implementation details live in these documents.
