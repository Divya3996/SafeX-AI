# Fraud model data attribution

SafeX AI 1.7 uses historical observed English messages and URL examples, a reported phishing-feed snapshot retrieved on 9 October 2026, and explicitly authored English/Hindi/Gujarati augmentation. The resulting models are limited research artifacts. Collection time is not incident time, and no source establishes protection against all fraud.

* **Sandhya Mishra and Devpriya Soni (2022)**, *SMS PHISHING DATASET FOR MACHINE LEARNING AND PATTERN RECOGNITION*, Mendeley Data, version 1, [DOI 10.17632/f45bkkt8pr.1](https://data.mendeley.com/datasets/f45bkkt8pr/1). CC BY 4.0. Used ham and smishing labels; excluded ambiguous spam labels.
* **Tiago Almeida and Jos Hidalgo (2011)**, *SMS Spam Collection*, UCI Machine Learning Repository, [DOI 10.24432/C5CC84](https://archive.ics.uci.edu/dataset/228/sms+spam+collection). CC BY 4.0. Used ham controls and removed cross-source duplicates. Its spam label was not converted into a fraud label.
* **Arvind Prasad and Shalini Chandra (2024)**, *PhiUSIIL Phishing URL (Website)*, UCI dataset 967, [DOI 10.1016/j.cose.2023.103545](https://archive.ics.uci.edu/dataset/967/phiusiil+phishing+url+dataset). CC BY 4.0. See [existing attribution](URL-DATA-ATTRIBUTION.md).
* **Phishing.Database contributors**, [reported phishing feed](https://github.com/Phishing-Database/Phishing.Database), MIT license. A complete 65,823,890-byte snapshot was collected locally; a deterministic sample of 40,000 reported HTTP(S) URLs was used. Active reports were not visited or independently adjudicated. The complete MIT notice is bundled in `android-app/app/src/main/assets/security-model-attribution.txt`.
* **SafeX authored patterns**, 20 behavioral categories with English/Hindi/Gujarati scam and legitimate-control examples. These are synthetic augmentation and contract tests, including examples used in training. They are not independently collected incidents or accuracy evidence.

The CC BY license is [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). Changes include numeric/address masking in text model features, deduplication, heuristic campaign grouping, URL-only feature extraction, bounded sampling, authored augmentation and fitted model weights. No source author endorses SafeX AI. Raw research data remains in ignored local cache files; the production APK contains model weights and this attribution, not the source collections. Native test APKs contain authored examples and a bounded historical URL parity fixture only.

See [collection manifest](fraud-data-manifest.json), [SMS preparation summary](fraud-message-data-summary.json), [URL preparation summary](fraud-url-data-summary.json), [text evaluation](fraud-text-evaluation.json), [URL evaluation](fraud-url-evaluation.json), and [research/access limits](../docs/fraud-research-2026-10-09.md). Reports contain counts and checksums rather than observed message text or threat URLs.
