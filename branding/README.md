# SafeX AI identity

[Master SVG](safex-logo.svg) is an original vector asset authored for this app. The matching Android vector is in `core/src/main/res/drawable/safex_logo.xml`; the adaptive launcher puts the same mark inside Android's safe icon area. A separate monochrome version is used for Android security notifications.

The shield stands for protection. The central **X** represents stopping a suspicious action before it causes harm. Three connected nodes represent local intelligence. The mark stays recognizable without relying on small lettering.

| Role | Color |
| --- | --- |
| Primary teal | `#35DEBC` |
| Midnight background | `#08151D` |
| Card surface | `#122936` |
| Raised surface | `#1B3544` |
| Primary text | `#EFF9F8` |
| Secondary text | `#A5BFCA` |
| Light-mode primary | `#007A68` |

Teal is used for navigation, selected controls and the brand. Separate green, amber and red colors communicate scan risk. System appearance follows the phone's light/dark choice using the SafeX palette. The existing Emerald preference remains available.

Use the SVG for presentation slides and exports. Preserve the shield proportions, the navy space around the X, and the node connections. App icons, onboarding, the home app bar, navigation drawer, and About use the same artwork.
